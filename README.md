# KnowledgeVault

AI-powered RAG application built with:

- React
- Node.js
- GraphQL
- PostgreSQL
- pgvector
- Ollama
- BullMQ
- Docker

---

## Features

- Upload PDF documents
- Semantic search using embeddings
- AI-powered chat
- Streaming responses (SSE)
- GitHub integration
- Jira integration
- Knowledge Vault
- Background ingestion using BullMQ

---

## Tech Stack

Frontend

- React
- TanStack Query
- TailwindCSS
- Axios

Backend

- Express
- GraphQL
- PostgreSQL
- pgvector
- Ollama

Infrastructure

- Docker
- Redis
- BullMQ
